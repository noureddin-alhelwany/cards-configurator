# cards-configurator – nur neue UI/UX Work Items

Dieses Paket enthält ausschließlich neue Work Items auf Basis des aktuellen Stands.

## Neue Entscheidungen

- Der sichtbare Flow beginnt mit Produkten.
- Use Cases bleiben ausschließlich intern.
- Felder, Texte, QR-Texte, Vorschläge und Validierungsregeln kommen aus dem gewählten Template.
- Bereits abgeschlossene Stories wurden nicht erneut aufgenommen.

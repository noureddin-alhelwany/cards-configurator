# Cards Designer – UI User Stories

Dieses Paket enthält alle User Stories für das neue Nutzer-Frontend des Cards Designers.

## Grundsatz

Das bestehende Frontend ist ein technischer Prototyp und wird vollständig entfernt.

Es werden **keine bestehenden HTML-Strukturen, Frontend-Komponenten oder CSS-Regeln übernommen**. Das neue Frontend wird von Grund auf neu aufgebaut.

Bestehen bleiben nur:

- Backendlogik
- APIs
- Datenmodelle
- Template-Konfigurationen
- Preview-Generierung
- Validierung und Qualitätsprüfung
- Auftragserstellung

## Ziel des neuen Frontends

Der Cards Designer soll bewusst einfach sein:

> Weniger Freiheit, weniger Fehler, schneller zu einem professionellen und druckfähigen Ergebnis.

Der Nutzer soll keine technische Konfiguration durchführen und keine freie Designfläche bedienen. Er wählt einen Zweck, ein Design und gibt seine Inhalte ein. Das System kümmert sich um Layout, Druckregeln und Qualitätsprüfung.

## Geplanter Nutzerflow

1. Auswahl
2. optional: Produkt
3. Design
4. Inhalte
5. Prüfen und Auftrag erstellen

Ein Produktschritt wird nur gezeigt, wenn mehrere sinnvolle Produkte verfügbar sind.

# Definition of Done – Neues UI-Fundament

Das UI-Fundament gilt als abgeschlossen, wenn:

- das alte Frontend vollständig entfernt wurde
- keine alte HTML- oder CSS-Struktur mehr verwendet wird
- der vollständige Nutzerflow mit dem neuen Frontend funktioniert
- das HTML semantisch und responsiv vorbereitet ist
- alle MVP-Backendfunktionen angebunden sind
- keine technischen Backendbegriffe im Nutzer-Frontend erscheinen
- alle wichtigen Lade-, Fehler- und Leerzustände vorhanden sind
- die Oberfläche per Tastatur bedienbar ist
- die Komponentenstruktur dokumentiert ist
- das spätere visuelle UI umgesetzt werden kann, ohne das HTML erneut grundsätzlich umzubauen

## Abgrenzung

Das Fundament muss funktional, verständlich und strukturell korrekt sein. Es muss noch nicht visuell final gestaltet sein.

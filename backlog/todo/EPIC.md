# Epic – Neues Nutzer-Frontend vollständig aufsetzen

## Ziel

Die aktuelle Entwickleroberfläche wird vollständig entfernt und durch ein neues, semantisches und komponentenbasiertes Nutzer-Frontend ersetzt.

Das neue HTML wird nicht aus dem bestehenden Markup weiterentwickelt. Es entsteht eine neue Struktur, die von Beginn an auf die spätere UI, Responsive Design, Accessibility und Wiederverwendbarkeit vorbereitet ist.

## Nutzerorientierter Flow

1. Auswahl
2. optional: Produkt
3. Design
4. Inhalte
5. Prüfen und Auftrag erstellen

## Zentrale Produktregeln

- Nur notwendige Entscheidungen anzeigen.
- Bei nur einer Möglichkeit automatisch auswählen.
- Keine technischen Backendbegriffe im Nutzer-Frontend.
- Keine leeren Templates.
- Keine freie Leinwand.
- Keine freie Positionierung von Designelementen.
- Gute Standardwerte statt vieler Optionen.
- Technische Druckregeln automatisch anwenden.
- Warnungen und Fehler verständlich formulieren.
- Die Vorschau muss jederzeit ein möglichst fertiges Ergebnis zeigen.

## Nicht Bestandteil dieses Epics

- finales visuelles Design
- Branding
- Marketing-Website
- Bezahlprozess
- Login und Benutzerverwaltung
- Versand
- freie Template-Erstellung durch Nutzer
